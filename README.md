# My Daily Planner

A beginner-friendly student To-Do List project made with HTML, CSS, and JavaScript.

## Features
- Add tasks with due dates and priority levels
- Mark tasks as completed or remaining
- Edit and delete tasks
- Filter all, remaining, and completed tasks
- View total, completed, and remaining task counts
- Save tasks in the browser using localStorage
- Responsive layout for desktop and mobile

## Files
- `index.html` — page structure
- `style.css` — design and responsive styles
- `script.js` — task interactions and browser storage

## Run locally
1. Download and extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Add your tasks.

No installation or server is required for local use.

## Publish with GitHub Pages
1. Create a GitHub repository named `my-daily-planner`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub Pages finishes publishing, use the URL shown in the Pages settings.

## Note
Tasks are stored in the browser on the device where you use the app. Clearing browser data may remove saved tasks.
